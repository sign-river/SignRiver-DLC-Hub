Steam 游戏目录扫描器 - 使用说明
================================

用途
----
自动查找电脑上的 Steam 库和已安装游戏，完整扫描后只导出维护者需要的
DLC/内容候选目录、补丁目录、Steam API 文件、补丁配置和游戏 EXE 路径。
普通资源文件不会逐条写入报告，因此报告体积较小。工具只读取目录和文件
信息，不会修改游戏文件。

使用方法
--------
1. 必须先把 ZIP 完整解压出来，请勿直接在压缩包预览窗口中运行。
2. 双击“Steam游戏目录扫描器.exe”。
3. 工具会自动扫描全部已安装 Steam 游戏，请耐心等待。
4. 扫描完成后，程序同目录会出现两个文件：
   - Steam游戏路径诊断报告_日期_时间.txt
   - Steam游戏路径诊断报告_日期_时间.json
5. 请把这两个文件一起发给维护者。

找不到 Steam 时
----------------
按照窗口提示，把 Steam 安装目录或 Steam 库目录拖进窗口，例如：
  C:\Program Files (x86)\Steam
  D:\SteamLibrary

常见问题
--------
- Windows 安全提示：这是未购买代码签名证书的独立工具，可选择“更多信息”后运行。
- 报告无法保存：请把 ZIP 解压到桌面或普通文件夹后再运行，不要放在只读目录。
- 报告包含文件路径、文件名和大小，但不会读取或上传文件内容；发送前可以自行查看。
