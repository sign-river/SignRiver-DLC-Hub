Steam 游戏目录扫描器（已融合 DLL 收集）- 使用说明
================================================

用途
----
一次运行完成两项工作：
1. 自动查找电脑上的 Steam、全部 Steam 库和所有已安装游戏，生成 DLC、
   补丁目录、Steam API 文件、补丁配置和游戏 EXE 路径诊断报告。
2. 找出每个游戏目录里的全部 steam_api64.dll，按游戏名称归类复制，
   最后将报告、DLL 清单和所有游戏子目录一起压缩成 ZIP。

工具不会修改或删除 Steam 游戏中的任何文件。普通资源文件不会逐条写入
报告，因此报告体积较小。

使用方法
--------
1. 必须先把 ZIP 完整解压出来，请勿直接在压缩包预览窗口中运行。
2. 双击“Steam游戏目录扫描器.exe”。
3. 工具会自动扫描全部已安装 Steam 游戏，请耐心等待。游戏较多或目录
   较大时可能需要几分钟。
4. 完成后，程序同目录会出现：
   - Steam_API64_DLL_收集_日期_时间 文件夹
   - 同名 .zip 压缩包
5. 收集文件夹和 ZIP 内包含：
   - Steam游戏路径诊断报告_日期_时间.txt
   - Steam游戏路径诊断报告_日期_时间.json
   - 收集清单.json
   - 按游戏名建立的子目录及对应 steam_api64.dll

如果一个游戏包含多个 steam_api64.dll，工具会保留 DLL 在游戏目录中的
相对路径，防止同名文件互相覆盖。没有该 DLL 的游戏不会创建空目录；程序
结束前会直接列出这些游戏的名称、AppID 和目录，并记录在“收集清单.json”中。

DLC 路径说明
------------
目录报告会把以下信息分开保存，避免把一次实际命中误当成唯一安装根目录：
- “DLC / 内容实际命中路径”：当前游戏目录中真实存在并命中的路径。
- “可能的 DLC 安装根目录”：从实际路径提取的上层候选，仅供人工判断。
- “推测子路径（未验证存在）”：按候选根目录和 DLC 目录名组合出的路径，
  不代表该路径当前真实存在。

例如实际命中 media_soviet\sounds\dlc1 时，报告会同时保留实际路径、
media_soviet 和 media_soviet\sounds 两个根目录候选，并提示未验证的
media_soviet\dlc1。最终 DLC 安装根目录仍应结合真实 DLC 包或实际安装结果确认。

找不到 Steam 时
----------------
按照窗口提示，把 Steam 安装目录或 Steam 库目录拖进窗口，例如：
  C:\Program Files (x86)\Steam
  D:\SteamLibrary

命令行用法
----------
  python collect_steam_api64.py
  python collect_steam_api64.py --out D:\Steam-DLL-Backup --no-pause
  python collect_steam_api64.py --library E:\SteamLibrary --no-pause

常见问题
--------
- Windows 安全提示：这是未购买代码签名证书的独立工具，可选择“更多信息”后运行。
- 无法保存：请把 ZIP 解压到桌面或普通可写目录后运行。
- 工具只在本地读取目录信息和 DLL 内容用于复制及 SHA-256 校验，不会上传文件。
- 目录报告和清单包含本机游戏路径；发送给他人前可以自行查看。
