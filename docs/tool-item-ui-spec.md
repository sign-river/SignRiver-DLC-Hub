# 生成工具项界面指标约束

> 本文档约束发布器或 AI 生成的拓展指南/工具元数据，避免客户端“常用工具”卡片出现文字截断，并记录客户端与发布器共同遵守的字段契约。修改指南/工具字段或显示规则时，必须同步更新本文档、示例和对应校验测试。

## 工具字段契约

工具条目同时维护在 `tools_index.json`（完整声明）和指南详情的 `tools` 引用（可选关联）。

- **`requires_cloud_download`**：布尔值，默认 `true`。需要从云端获取工具包时填 `true`；工具由客户端本地能力提供、不需要云端附件时填 `false`。
- 填 `false` 时，客户端详情页直接显示“已就绪”，不会把本地工具误报为“未下载”；该字段不改变工具动作白名单或安全限制。
- 指南详情引用该工具时，如显式填写此字段，必须与 `tools_index.json` 完全一致；建议始终显式填写，便于发布审核和后续维护。

```json
{
  "tool_id": "local-diagnostic",
  "title": "本地诊断",
  "description": "读取本机状态并给出诊断提示；不修改系统设置。",
  "requires_cloud_download": false,
  "platforms": ["windows"]
}
```

## 简略描述（当前生效）

- **字段**：工具项的 `description`，用于“常用工具”卡片摘要。
- **硬上限**：不超过 **45 个字符**（按 Python `len` 计数；汉字、英文、数字、空格和标点均计入）。
- **推荐长度**：36～42 个字符；尽量控制为一句话。
- **内容要求**：先说明用途，再补充一个关键限制或安全边界；不要重复工具标题、下载按钮或详情页已有信息。
- **格式要求**：单行纯文本，不使用换行、Markdown、连续空格或句末标点（如 `。`、`.`、`！`、`!`）。
- **超限处理**：生成阶段应直接重写到上限以内，不要依赖客户端截断来掩盖超长内容。客户端卡片摘要仍保留防御性截短，详情页显示完整原文，避免远程索引内容破坏布局。

## 工具详情正文显示

- `detail.intro`、完整 `description` 和内置工具的说明文字统一使用客户端只读 `CTkTextbox` 呈现，不使用固定 `wraplength` 的 `CTkLabel` 承载长正文。
- 文本框使用字符换行、关闭自身滚动条，并按实际显示行数自动调整高度；页面滚动由详情页外层滚动容器负责。
- 新增工具详情正文时必须复用现有文本框渲染入口，确保窄窗口、高 DPI 和中文长句仍能完整换行显示。
- 显卡名称、驱动版本、状态等需要快速识别的结构化重点信息，可使用带强调边框的专用信息块；信息块内部仍必须复用只读文本框的自动换行能力，不得退回固定 `wraplength` 标签。

### 推荐模板

```text
用于[核心用途]；[一个关键限制或安全边界]。
```

### 示例

```text
整理游戏日志、配置、问题记录和 DxDiag 报告；不收集截图或大型转储。
```

## 后续待补充指标

- 工具标题长度与换行策略；
- 卡片按钮文案、宽度和最小可点击尺寸；
- 卡片摘要字号、行数与间距；
- 工具项数量、网格列数和不同窗口尺寸下的适配规则；
- 详情页正文、附件文件名及其他元数据限制。
## 指南与工具详情跳转

- 指南详情顶部不添加固定的工具管理按钮；工具下载、启动和删除统一由工具详情页负责。
- 指南仅在确有需要时通过正文 `button` 块声明 `target: "tool:<tool_id>"`，跳转到对应工具详情页。
- 工具详情页可按需提供关联指南入口；从指南进入工具时，返回按钮回到原指南。

### Windows 内置 P 社启动器工具

- `P 社启动器修复` 与 `P 社启动器安装工具` 是客户端内置工具，不依赖 `tools_index.json` 或云端工具附件，详情页顶部状态固定显示“已就绪”。
- 启动器修复操作必须先确认 `launcher.exe` 未运行，再定位 `%LOCALAPPDATA%/Programs/Paradox Interactive/launcher` 下最新可用版本目录；仅当目标目录包含 `resources/app.asar.unpacked/node_modules/greenworks/lib/steam_api64.dll` 时才允许处理。
- 工具详情中的“打开启动器安装文件夹”与“启动器修复”共用同一目录探测逻辑；启动器运行时不得替换文件，应提示用户退出后重试。
- 安装工具只负责下载官方安装程序、打开安装程序/下载文件夹和删除本地安装程序，不进入程序自动更新流程；官网和 QQ 群入口使用受控 HTTPS 链接。

### 报错指南链路按钮层级

以下规则仅适用于“报错指南”首页、解决方案、常用工具、一键排错和问题记录，以及它们的详情页；侧栏独立的运行日志和其他业务大类不受本节约束。

- **主操作**使用蓝色实心 `BUTTON_PRIMARY`。一个详情页或任务页只突出一个当前主任务，例如开始排错、下载工具、重新下载补丁、开始收集资料或安全重试。
- **普通操作**使用浅蓝描边 `BUTTON_SECONDARY`，包括返回、查看教程或详情、打开目录/文件/系统页面、刷新、复制、暂停和标记已解决等跳转或辅助操作。例外：侧栏“运行日志”页的“复制当前日志”和问题详情底部的“复制详情”是各自页面的核心信息导出操作，使用蓝色实心 `BUTTON_PRIMARY`；其他复制操作仍使用普通样式。
- 安全提示卡默认采用白色 `UI["card"]` 背景。若卡片内的教程入口是用户处理当前安全提示的关键下一步，可使用蓝色实心 `BUTTON_PRIMARY`；其余普通按钮仍使用 `BUTTON_SECONDARY`。
- **危险操作**使用红色描边 `BUTTON_DANGER`，包括删除下载、卸载工具、删除问题记录、清空全部记录和终止检测。不得将这些操作渲染为蓝色实心按钮。
- 动态按钮必须根据当前语义同步切换样式：下载工具为主操作，暂停下载为普通操作，删除下载为危险操作；问题记录中的安全重试、删除和其他操作也分别遵循以上三层规则。

### 补丁文件状态

- 补丁工具应始终列出当前发布包声明的全部补丁文件，不能因为某项尚未下载而隐藏整行。
- 已下载且缓存文件可访问的项目应在右侧操作列前显示绿色“补丁正常”标记，并显示“打开位置”（可直接打开的文件同时显示“打开文件”）；未下载、缓存丢失、校验失败、下载失败或取消时，隐藏这些操作并在行右侧显示对应的状态提示。

### Windows 图形设备兼容性工具

- 内置 `graphics-compatibility` 工具仅在 Windows 显示；只允许读取和修复固定的四项 DirectDraw/Direct3D 注册表值。
- 修复必须经过用户确认、管理员权限检查和备份，完成后提示重启；不得接受用户输入的注册表路径、命令或脚本，也不得自动更新驱动、关闭防护或重启系统。
- 详情页提供打开 DirectX 诊断工具、修复和恢复本次备份按钮；不自动解析或展示 `dxdiag` 加速结论，由用户在系统“显示”页确认。
