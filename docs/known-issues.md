## 待处理

### KI-001：一键排错将充足的磁盘空间误显示为红色

- **状态**：待排期
- **优先级**：P2（体验问题，不阻断功能）
- **发现日期**：2026-08-23
- **影响范围**：客户端“一键排错”中的游戏目录磁盘空间检查；当前活动模块为 `0.2.0`。
- **现象**：游戏目录所在磁盘仍有约 110 GB 可用空间时，检查结果显示为红色，并出现“查看解决方案”按钮。
- **复现条件**：选择存在的游戏目录后运行“一键排错”。
- **当前原因**：`_quick_check_game_directory()` 无论剩余空间多少都会传入 `disk-space` 解决方案 ID；渲染逻辑只要存在该 ID 就使用危险色并显示解决方案入口。
- **期望行为**：仅当可用空间低于明确阈值时标红并展示磁盘空间解决方案；空间充足时应以普通颜色显示，并明确提示空间充足。
- **计划修复版本**：未定；与下一批“一键排错”体验优化统一处理。
- **验收要点**：覆盖低于阈值、等于阈值和高于阈值三种空间值，验证颜色、文字和解决方案入口均符合预期。

### KI-002：启动时反复输出报错指南缓存/详情格式警告

- **状态**：待排期
- **优先级**：P2（日志噪音，可能影响可选报错指南内容）
- **发现日期**：2026-08-23
- **影响范围**：客户端启动时的报错指南远端索引、本地缓存索引与可选详情加载；当前活动模块为 `0.2.0`。
- **现象**：从源码运行 `launcher.py` 时，控制台反复输出 `Ignoring invalid remote/cache guide index: unsupported guide schema`，以及多个 `guide_id must be a lowercase id` 警告；但随后仍输出 `Starting application module 0.2.0`。
- **复现条件**：当前工作区保留 `data/guides/` 中的缓存数据后启动客户端。
- **已知行为**：客户端将不符合当前 schema 或 ID 校验规则的远端/缓存指南主动忽略，并继续尝试使用其他可用来源，因此该日志本身不表示客户端启动失败。
- **待确认原因**：缓存索引 schema 与当前客户端要求不一致；可选详情文件的 `guide_id` 校验失败。需后续核对缓存生成、下载保存与路径/ID 转换链路，确认是历史缓存遗留、文件命名转换还是远端内容格式问题。
- **期望行为**：兼容可安全迁移的旧缓存，或在发现不可用缓存后一次性清理/刷新并避免重复告警；用户界面应仍能可靠展示内置或已验证的指南。
- **计划修复版本**：未定；与下一批报错指南缓存体验优化统一处理。
- **验收要点**：准备旧 schema、无效 ID 与合法缓存三类样本，验证启动不受阻、每类警告不重复刷屏、可用指南正常加载，且无效缓存可被安全刷新或忽略。
